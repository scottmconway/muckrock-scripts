# Muckrock Scripts
A collection of scripts for useful actions on [Muckrock](https://www.muckrock.com), using [their API](https://www.muckrock.com/api_v2/).

Code in this repository was largely generated by an LLM. LLMs were not used in the writing of this readme.

## Requirements
* python3
* requests

## Configuration Setup
See `config.json.exmaple` for an example configuration file.

`auth_info` requires valid Muckrock credentials.
The contents of the `logging` section are passed directly to `logging.config`'s `dictConfig` intializer. See [logging's documentation](https://docs.python.org/3/library/logging.config.html#logging.config.dictConfig) for what information can be provided here.

## Scripts
### `alert_on_requests_update.py`
This script logs INFO statements when a request submitted by the logged-in user has had a status change. It is intended to run as a cronjob. The last status is not provided via the Muckrock API, and is thus tracked through a local json file (./status.json).

Unfortunately, the API does not expose the user's followed requests. Thus at this time the script only alerts on requests submitted by the logged-in user. It could be easily altered to check the status of arbitrary requests via entries in the config file, but that does not match my use-case.

## A note on python-muckrock
Muckrock maintains an API wrapper called [python-muckrock](https://pypi.org/project/python-muckrock/), but as of its latest release on 2026-06-15 (2026-11-18 writing), it requires python versions between 3.7 and 3.12 inclusive. I'm not sure why that is, but it's enough to steer me away from it!
